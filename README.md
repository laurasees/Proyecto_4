## Análisis Exploratorio de Datos (EDA) - Campaña de Marketing Bancario

Este proyecto realiza un **Análisis Exploratorio de Datos (EDA)** combinando información de interacciones comerciales de una entidad bancaria y datos demográficos de clientes. El objetivo principal es identificar el perfil de los clientes con mayor probabilidad de contratar un depósito a plazo fijo y evaluar la eficacia de las campañas telefónicas.

---

## Las tecnologías que he usado para el proyecto han sido

* **Lenguaje:** Python 3.14
* **Entorno de desarrollo:** Visual Studio Code (Jupyter Interactive Engine)
* **Librerías principales:**
  * `pandas`: Carga, consolidación, limpieza y transformación de datos.
  * `numpy`: Operaciones numéricas y vectoriales.
  * `matplotlib` & `seaborn`: Visualización de datos y generación del panel gráfico.
  * `openpyxl`: Lectura del archivo de datos demográficos en formato Excel multihoja.
